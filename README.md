# ЖНЕЦЫ — мобильная .io игра

100 жнецов, 5 областей, кирки, пшеница, гусеницы и блоки. Управление: палец — движение, двойной тап — рывок, кнопка — блок.

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка в dist/
```

## Публикация на GitHub Pages

Сборка использует относительные пути (`base: "./"`), поэтому игра работает из любого подкаталога.

### Способ 1 — автоматически (рекомендуется)

1. Залейте проект в репозиторий на GitHub.
2. В репозитории: **Settings → Pages → Source** → выберите **GitHub Actions**.
3. Сделайте `git push` — workflow `.github/workflows/deploy.yml` соберёт и опубликует игру.
4. Через 1–2 минуты игра доступна по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

### Способ 2 — веткой gh-pages

```bash
npm run build
npx gh-pages -d dist
```

Затем **Settings → Pages → Source** → ветка `gh-pages`, папка `/ (root)`.

## Если страница белая

- Проверьте, что в **Settings → Pages** включён деплой и он завершился без ошибок (вкладка Actions).
- Откройте DevTools → Network: все ассеты должны отдаваться со статусом 200 из папки репозитория, а не из корня сайта.
